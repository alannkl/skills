---
name: handoff
description: Writes a handoff note so another session can continue this one.
disable-model-invocation: true
---

1. Summarize the goal and what is done, with the files and commits involved.
2. List what is left, in the order to do it.
3. Note decisions made and why, and any dead ends already tried.
4. Write it to `HANDOFF.md` at the repository root, replacing any older one.
5. Tell the user the path and the first step for the next session.
